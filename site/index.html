还有一只小章鱼And a tiny octopus

Tako 住在刘海里，心情跟着服务器走：在跑就忙，全完成了就开心，出错了会变红。 Tako lives in the notch and mirrors your servers: busy while jobs run, happy when they finish, red when something fails.

为算材料、算化学、算物理的人而做Built for computational materials, chemistry and physics

不用再开终端敲 squeue、nvidia-smi、tail loss.out。Stop typing squeue, nvidia-smi and tail loss.out all day.

01

每台服务器一张卡片One card per server

鼠标移到刘海上就展开。集群和工作站分开显示，每张卡片上有自己的运行数、排队数、CPU / 内存 / GPU。没有任务的机器自动合并成一行，不占地方。 Hover the notch to expand. Clusters and workstations each get a card with their own running / pending counts, CPU, memory and GPUs. Idle servers fold into a single line.

  • 读取 ~/.ssh/config，跳板机、密钥都照常生效Reads ~/.ssh/config — ProxyJump and keys just work
  • 动态口令集群：输入一次，连接一直保持OTP clusters: log in once, stay connected
  • 每台机器可以单独暂停、静音、设轮询间隔Pause, mute or set the interval per server
02

Slurm：数组、排队原因、分区空闲Slurm: arrays, pending reasons, free nodes

几十个元素的数组作业合并成一行，绿 / 红 / 蓝分段显示完成、失败、运行中。排队原因翻译成人话；需要你处理的（比如依赖永远无法满足）会标红。还能按需查看各分区还有多少空闲 CPU 和 GPU。 Job arrays collapse into one row with done / failed / running segments. Pending reasons are explained in plain words, and the ones that need you are flagged. Check free CPUs and GPUs per partition on demand.

03

完成和失败，刘海会告诉你The notch tells you when it's done

任务结束时刘海弹出提示，成功和失败是两种不同的提示音。没有开启作业记录的集群，也会按计算软件的输出判断是正常结束还是提前退出，不靠猜。 When a job ends, the notch pops up — with different sounds for success and failure. Even on clusters without job accounting, ServerIsland checks the software's own output to tell a clean finish from an early exit.

04

点开就是详情和日志末尾Details and log tail, one click away

作业信息、工作目录、实时刷新的日志末尾，一键复制路径或 tail -f 命令。取消任务默认关闭；打开后也要长按、二次确认，执行前还会在服务器上再核对一遍。 Job info, working directory and a live log tail; copy the path or a tail -f command in one click. Cancelling is off by default — and even when on, it takes a long press, a confirmation and a server-side re-check.

认识你的计算软件Knows your simulation software

按工作目录里的文件判断，只读文件末尾。格式和预期不一致时宁可不显示，也不给你一个错的进度。 Detected from files in the working directory, reading only their tails. If anything doesn't match, it shows nothing rather than a wrong number.

NEP / GNEPloss.out + nep.in

代数、loss、预计剩余时间；详情页有 loss 曲线Generation, losses, ETA — plus a loss curve

GPUMDrun.in + thermo.out

步数和速度，目标是 run.in 里所有 run 之和Steps and speed; target is the sum of all runs

VASPINCAR + OSZICAR

MD 显示百分比；结构优化显示离子步和能量曲线MD as a percentage; relaxations show ionic steps and an energy curve

LAMMPSlog.lammps

最后一段 run 的步数；以 Total wall time 判断正常结束Steps of the last run; "Total wall time" marks a clean finish

只在你的电脑上运行Runs only on your computer

没有账号、没有云端、不收集任何数据。所有连接都是你的电脑直接 ssh 到你的服务器。No account, no cloud, no telemetry. Your computer talks to your servers over ssh, and that's it.

用系统自带的 sshUses the system ssh

密钥、密码、密钥 + 密码、动态口令和跳板机都能用。密码在原生对话框里输入，默认不保存；连接复用后不再打扰。Keys, passwords, key + password, one-time codes and jump hosts all work. Passwords go into a native dialog and aren't stored by default; the connection is then reused.

轻量到感觉不到Featherweight

每台机器每轮一个 SSH 通道，只读小文件和文件末尾；可以按机器调间隔，或只手动刷新。One SSH channel per server per poll, reading only small files and tails. Tune the interval per server, or refresh manually.
